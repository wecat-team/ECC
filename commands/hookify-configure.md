Bật hoặc tắt các rule hookify hiện có theo cách tương tác.

## Các bước

1. Tìm tất cả file `.claude/hookify.*.local.md`
2. Đọc trạng thái hiện tại của từng rule
3. Hiển thị danh sách kèm trạng thái enabled / disabled hiện tại
4. Hỏi những rule nào cần chuyển trạng thái
5. Cập nhật trường `enabled:` trong các file rule đã chọn
6. Xác nhận các thay đổi
